## Overview
Phase 0 establishes the essential foundation for your NexaBank engineering journey. It bridges foundational computing concepts with your first practical Java implementation, ensuring you understand the tools, systems, and mindset required to build robust software. This phase demystifies how computers, networks, and development environments function while guiding you to create the initial Java class that will serve as the entry point for your banking platform. By grounding you in both theory and immediate practice, it prepares you to tackle increasingly complex engineering challenges in subsequent phases.

## Phase Objectives
- Understand computational systems and data representation fundamentals (binary, bits/bytes)
- Navigate operating systems, file systems, and command-line interfaces
- Grasp internet protocols and network communication basics
- Configure a Java development environment
- Write your first Java class as the NexaBank application entry point
- Develop a growth mindset for iterative engineering problem-solving

## Phase Outcome
- A fully configured Java development environment ready for NexaBank development
- A functional `Main.java` class serving as the application entry point
- Foundational knowledge of computing systems, data representation, and networks
- Practical command-line proficiency for project management
- Internalized growth mindset strategies for tackling engineering obstacles

## Next Steps
In Phase 1, you'll expand your single Java class into a command-line interface (CLI) for NexaBank, introducing object-oriented programming (OOP) principles to model core domain entities like `Customer` and `Account`. This phase will transform your foundational entry point into a structured application framework, preparing you to implement banking operations in subsequent phases.
